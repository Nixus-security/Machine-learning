Méthodologie
  • Données : 195 voitures complètes, 13 variables numériques standardisées, split 80 / 20 identique (générateur LCG commun).
  • Python : NumPy vectorisé (OpenBLAS). Rust : bibliothèque standard uniquement, compilé en --release ; le réseau de neurones exploite le SIMD et tous les cœurs (threads).
  • Test en direct (3D) : python live.py, les deux langages s'entraînent en parallèle sur 1 cœur chacun.
  • Le temps mesuré exclut l'enregistrement des états utilisés pour l'animation.
